# Third-party software and data

No third-party dataset, checkpoint, feature cache, or model output is
redistributed in this repository.

| Asset | Upstream source | Use |
|---|---|---|
| OpenOOD v1.5 | <https://github.com/Jingkang50/OpenOOD> | Benchmark splits, pretrained checkpoints, and comparison-method protocol |
| CIFAR-10/100 | <https://www.cs.toronto.edu/~kriz/cifar.html> | ID and OOD benchmarks |
| ImageNet | <https://www.image-net.org/> | Source of ImageNet-200 |
| Tiny ImageNet | <http://cs231n.stanford.edu/tiny-imagenet-200.zip> | OOD data |
| MNIST | <http://yann.lecun.com/exdb/mnist/> | OOD data |
| SVHN | <http://ufldl.stanford.edu/housenumbers/> | OOD data |
| DTD | <https://www.robots.ox.ac.uk/~vgg/data/dtd/> | OOD data |
| Places365 | <http://places2.csail.mit.edu/> | OOD data |
| NINCO | <https://github.com/j-cb/NINCO> | OOD data |
| OpenImage-O | OpenOOD distribution | OOD data |
